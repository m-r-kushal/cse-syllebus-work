## Motivation

Web Engineering Lab complements the theory course by giving students hands-on experience in building full-stack web applications. Using modern frontend and backend frameworks, students will learn how to implement secure, database-driven, and maintainable web systems.

## Course Objective

This laboratory course develops practical skills in full-stack web development using React on the frontend and a modern server-side web framework on the backend. Students will design APIs, connect databases, implement authentication, integrate frontend and backend modules, test web applications, and package them using modern development tools.

## Lab Course Contents / List of Experiments

- Lab 1 — Environment Setup and Project Structure
- Lab 2 — Backend Framework Basics and Database Migrations
- Lab 3 — REST API Development with Postman
- Lab 4 — Authentication and Role-Based Access
- Lab 5 — React–API Integration
- Lab 6 — Full-Stack CRUD Module
- Lab 7 — File Uploads, Security, and Validation
- Lab 8 — Testing, Debugging, and API Documentation
- Lab 9 — Dockerization and Capstone Project
